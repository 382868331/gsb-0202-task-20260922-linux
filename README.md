# tps2d — 二维薄板样条（Thin-Plate Spline）形变模块

离线医学配准工程使用的可复用 2-D TPS fit/warp 库。**纯 Python 3.14.7 标准库实现**，
无任何第三方依赖；不调用第三方 TPS 实现替代核心算法。仅支持 Linux 原生运行，
安装 Python 后不需要安装其他任何东西。

## 运行环境与命令

- Python：**3.14.7**（代码仅使用 `math`、`dataclasses` 等标准库，3.10+ 语法亦可运行，但以 3.14.7 为准）
- 依赖：无（`requirements.txt` 为空注释）
- 网络 / 账号 / 密钥 / 数据库 / 中间件 / 云 API / Docker：均不需要

```bash
# 必要测试（38 个用例）
python -m unittest discover -s tests -v

# 固定输入演示（约 0.03 秒，上限要求约 8 秒内）
python demo.py
```

两条命令都在仓库根目录执行，全程离线、无 `sleep`、无预录结果。

## 数学定义

对控制点 `c_i = (x_i, y_i)` 与目标点 `v_i = (x'_i, y'_i)`，两个输出坐标独立拟合

```
f(p) = a0 + a1*x + a2*y + Σ_i w_i · U(‖p − c_i‖)
U(r) = r²·log(r),   U(0) = 0
```

实现上用代数等价形式 `U = 0.5·r²·ln(r²)`（避免开方，并直接定义原点为 0）。
求解带约束的线性方程组（`K_ij = U(‖c_i − c_j‖)`）：

```
┌ K + λI   P ┐ ┌ w ┐   ┌ v ┐
│ Pᵀ       0 │ │ a │ = │ 0 │ ,   P_i = [1, x_i, y_i]
└           ┘ └   ┘   └   ┘
```

底部三行即约束 **Pᵀw = 0**（两个坐标分别满足）。x、y 两个输出坐标共享同一
系数矩阵、独立右端项，一次消元同时求解。

## 公开接口

```python
from tps2d import fit, TPSInputError, DegeneratePointsError, MAX_CONTROL_POINTS

result = fit(sources, targets, lam=0.0)
```

- `sources` / `targets`：`list[list[float, float]]`，长度 1～40 且相等。
- `lam`：正则参数，实数，`lam >= 0`，量纲为**长度²**（与 K 中 r² 对应）。
  `lam=0` 精确插值；增大则以拟合残差换平滑。同一形变在坐标整体放大 s 倍时，
  等效 λ 为原值的 s² 倍（内部按归一化问题求解，见设计取舍）。
- `MAX_CONTROL_POINTS = 40`。

返回 `TPSFitResult`（dataclass）：

| 字段 | 含义 |
|---|---|
| `warp` | `TPSWarp`，用于求值与 Jacobian |
| `weights` | n×2 非仿射系数 `w`（每个合并后控制点一行，列为输出 x/y） |
| `affine` | 3×2 仿射系数 `[[a0x,a0y],[a1x,a1y],[a2x,a2y]]` |
| `residuals` | 每个控制点处的欧氏残差 `‖f(c_i) − target_i‖` |
| `rms_residual` | 两坐标全部控制点的 RMS 残差 |
| `bending_energy` | 弯曲能二次型 `wᵀKw`，两输出坐标求和；纯仿射时为 0 |
| `rank` | 仿射设计矩阵 P 的数值秩（合法拟合恒为 3） |
| `merged_count` | 合并同目标重复点后的不同源点个数 |

`TPSWarp` 方法：

```python
warp.evaluate([x, y])          # -> [x', y']，单点
warp([x, y])                   # 同上（可调用别名）
warp.warp_points([[x,y], ...]) # -> [[x',y'], ...]，批处理
warp.jacobian([x, y])          # -> 2×2 [[dfx/dx, dfx/dy],[dfy/dx, dfy/dy]]
```

Jacobian 由核函数解析导数给出：`∂U/∂x = dx·(ln r² + 1)`，在控制点处（r=0）
方向导数取 0，结果有限。

## 错误语义（非法输入不静默纠正）

所有错误抛出 `TPSInputError`（`ValueError` 子类），信息携带可定位的下标/字段名；
退化构型抛出其子类 `DegeneratePointsError`。

- 坐标或 `lam` 为 `NaN` / `±Infinity` → 拒绝；
- `bool` 不是数字（`True/False` 即使可当 `int` 也显式拒绝，包括 `lam=True`）；
- 非数值、点不是二元序列、空列表、源/目标长度不符、超过 40 点 → 拒绝；
- `lam < 0` → 拒绝；
- **重复源点、目标不同 → 拒绝**（错误信息给出冲突的两个目标）；
- **重复源点、目标相同 → 合并**为一个控制点（`merged_count` 反映）；
- 合并后少于 3 个不同点，或点共线（P 的数值秩 < 3）→ `DegeneratePointsError`。

重复点判定采用转换后浮点数的**精确相等**，不做容差吸附（见已知限制）。
批次操作 `warp_points` 先整体校验再计算，任何元素非法都不会产生部分结果，
`warp` 对象在失败调用后保持可用。求解为确定性直接消元，不存在“搜索预算”
概念；数学上无解/不可解的情形统一由上述异常报告。

## 数值误差口径

IEEE-754 binary64（双精度），部分主元高斯消元。测试断言口径（不使用宽容差
掩盖边界错误，退化判定与容差相互独立）：

- `lam=0` 控制点恢复、纯仿射解析参考、本库 vs 独立参考实现：**绝对误差 < 1e-9**
  （演示的 O(1) 坐标实测残差约 1e-15）；
- 坐标量级达 1e6（典型大像素坐标）：控制点残差与探测点输出的**相对误差 < 3e-9**
  （实测约 2.5e-9，主要来自大坐标表示误差）；
- 约束 `Pᵀw = 0`：各分量绝对误差 < 1e-8；
- 解析 Jacobian vs 中心有限差分（h=1e-6，普通点，坐标 O(1)）：**< 5e-5**
  （演示实测约 1e-9；控制点处用 h=1e-5，阈值 2e-4，因核函数在原点曲率奇异；
  像素尺度（~1e3）实测 Jacobian 最大偏差约 1e-9，差分步长与坐标量级匹配）；
- 共线判定阈值：离轴偏差小于构型直径 **1e-12** 倍即视为退化（约 4.5×10³ 倍
  机器精度，刻意收紧）；消元主元阈值为 `(n+3)·eps·max|A_ij|`。

阈值的含义明确：1e-12 直径以内的近共线构型会被当作退化拒绝，而不是带着
近奇异矩阵硬解。

## 设计取舍

- **自带稠密线性求解器**（`tps2d/_linalg.py`）：系统最大 43 阶，纯 Python O(n³)
  消元耗时为毫秒级，换取零依赖、可审计；
- 两输出坐标共用同一次消元（多右端项），不重复分解；
- **内部归一化**：求解前把源点中心化并按点集直径 s 缩放到 [-1,1] 量级，
  目标点除以 s，正则量换算为 `lam/s²`，求解后再把系数精确换回原单位
  （利用 `U(sr)=s²U(r)+s²ln(s)r²` 与 `Pᵀw=0`，二次附加项退化为并入 a0 的
  常数）。这样避免了像素级大坐标（1e3..1e6）下 K 块量级淹没 Schur 补主元、
  被误判奇异的问题；公开系数、残差、Jacobian 全部保持调用方单位；
- 弯曲能直接由 K 与 `w` 组装（对角线 U(0)=0），报告的是**代数二次型
  `wᵀKw`（两坐标之和）**，不含经典物理泛函中的常数因子（如 8π 等），
  也不含 λ 罚项——`lam>0` 时它仍表示几何弯曲能，故应随正则增强而单调下降；
- 测试期望值来自闭式构造（已知仿射）或 `tests/_reference.py` 中**从零另写**
  的独立参考（独立核函数、独立 Gauss-Jordan 消元、独立组装），被测核心
  从不用于产生自己的期望值；往返一致性检查仅作补充；
- 不提供图像重采样 / 浏览器 / GUI，本模块只做点对曲面的 fit、warp 与导数。

## 已知限制

- 仅二维、控制点 ≤ 40；不实现 3-D TPS 或图像级配准；
- 重复点按精确浮点相等判定，不做近邻吸附/容差合并（需要时由调用方预先归并）；
- 弯曲能为代数口径 `wᵀKw`，未乘经典文献的归一化常数；
- 近退化构型（离轴 < 1e-12 直径）一律报退化，不尝试奇异值截断求解；
- 不声明与任何行业配准标准的完整兼容性，只实现本契约的数学子集。
