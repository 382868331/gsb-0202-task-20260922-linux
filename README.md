# tps2d — 二维薄板样条（Thin-Plate Spline）形变模块

离线医学配准工程使用的可复用 2-D TPS fit/warp 库。**纯 Python 3.14.7 标准库实现**，
无任何第三方依赖；不调用第三方 TPS 实现替代核心算法。仅支持 Linux 原生运行，
安装 Python 后不需要安装其他任何东西。

## 运行环境与命令

- Python：**3.14.7**（代码仅使用 `math`、`dataclasses` 等标准库，3.10+ 语法亦可运行，但以 3.14.7 为准）
- 依赖：无（`requirements.txt` 为空注释）
- 网络 / 账号 / 密钥 / 数据库 / 中间件 / 云 API / Docker：均不需要

```bash
# 必要测试（63 个用例）
python -m unittest discover -s tests -v

# 固定输入演示（实测约 0.04 秒，上限要求 90 秒内）
python demo.py
```

两条命令都在仓库根目录执行，全程离线、无 `sleep`、无预录结果。

## 数学定义

对控制点 `c_i = (x_i, y_i)` 与目标点 `v_i = (x'_i, y'_i)`，两个输出坐标独立拟合

```
f(p) = a0 + a1*x + a2*y + Σ_i w_i · U(‖p − c_i‖)
U(r) = r²·log(r),   U(0) = 0
```

实现上用代数等价形式 `U = 0.5·r²·ln(r²)`（避免开方，并直接定义原点为 0）。

**插值（`lam = 0`）**：在约束 `Pᵀw = 0` 下解经典块方程组
（`K_ij = U(‖c_i − c_j‖)`），两个输出坐标共享系数矩阵：

```
┌ K   P ┐ ┌ w ┐   ┌ v ┐
│ Pᵀ  0 │ │ a │ = │ 0 │ ,   P_i = [1, x_i, y_i]
└       ┘ └   ┘   └   ┘
```

**带置信权重的平滑（`lam > 0`，`sigma_i >= 0` 为每点置信权重）**：
最小化

```
Σ_i sigma_i · (f(c_i) − v_i)²  +  lam · wᵀKw,   约束 Pᵀw = 0
```

记残差 `r = v − Kw − Pa`、`W = diag(sigma)`，驻点条件为 `w = Wr/lam`。
实现不直接用含 `1/lam` 的残差形式，而是在**同一个 (n+6) 阶 KKT 块方程组**
里联合求弯曲系数 `w`、仿射系数 `a` 与拉格朗日乘子 `μ`，各块在归一化单位下
对任意 `lam >= 0` 均为 O(1) 量级，λ→0 时连续退化为受信点上的插值问题：

```
┌ lam·K + KWK   KWP   P ┐ ┌ w ┐   ┌ KWv   ┐
│ PᵀWK          PᵀWP  0 │ │ a │ = │ PᵀWv  │
└ Pᵀ            0     0 ┘ └ μ ┘   └ 0     ┘
```

`sigma_i = 0` 的点数学上恒有 `w_i = 0`（对曲面没有任何核贡献），直接从求解
系统剔除，之后以零系数行补回；`sigma ≡ 1` 时结果与经典 `K + lam·I` 平滑
样条代数一致（旧测试逐点验证）。x、y 两个输出坐标共用一次消元。

## 公开接口

```python
from tps2d import fit, TPSInputError, DegeneratePointsError, MAX_CONTROL_POINTS

result = fit(sources, targets, lam=0.0)                       # 旧用法不变
result = fit(sources, targets, lam=0.5, confidence=weights)  # 新增置信权重
```

- `sources` / `targets`：`list[list[float, float]]`，长度 1～40 且相等。
- `lam`：非负正则参数（`bool` 拒绝），量纲为**长度²**（与 K 中 r² 对应）。
  `lam=0` 精确插值；增大则以拟合残差换平滑。同一形变坐标整体放大 s 倍时，
  等效 λ 为原值的 s² 倍（内部按归一化问题求解，见设计取舍）。
- `confidence`：**新增**关键字参数，每点一个 `>= 0` 的实数（`bool`/NaN/Inf/
  负数拒绝），长度必须与点数一致；缺省等价于全 1。量纲是 `1/长度²`
  （与目标残差平方配对，见数学定义；σ 与 1/λ 同时放大同一倍数结果不变）。
  `sigma_i = 0` 表示完全不信任该点，仅在 `lam > 0` 时合法。重复源点且目标
  相同时，置信度相加（同一观测的精度累加）。
- `MAX_CONTROL_POINTS = 40`。

返回 `TPSFitResult`（dataclass）：

| 字段 | 含义 |
|---|---|
| `warp` | `TPSWarp`，用于求值与 Jacobian |
| `weights` | n×2 非仿射系数 `w`（每个合并后控制点一行，列为输出 x/y）；零权重点对应行为精确 0 |
| `affine` | 3×2 仿射系数 `[[a0x,a0y],[a1x,a1y],[a2x,a2y]]` |
| `residuals` | 每个合并控制点处的欧氏残差 `‖f(c_i) − target_i‖`（含零权重点） |
| `rms_residual` | 两坐标全部控制点的 RMS 残差 |
| `bending_energy` | 弯曲能二次型 `wᵀKw`，两输出坐标求和；纯仿射时为 0 |
| `rank` | **受信点**（lam>0 时为 σ>0 的点）仿射设计矩阵 P 的数值秩（合法拟合恒为 3） |
| `merged_count` | 合并同目标重复点后的不同源点个数 |
| `confidence` | **新增**；实际使用的每点置信度（重复点已相加）；调用方未传时为 `None` |
| `effective_count` | **新增**；严格正权重（真正参与拟合）的合并点数；插值时等于 `merged_count` |

`TPSWarp` 方法：

```python
warp.evaluate([x, y])          # -> [x', y']，单点
warp([x, y])                   # 同上（可调用别名）
warp.warp_points([[x,y], ...]) # -> [[x',y'], ...]，批处理
warp.jacobian([x, y])          # -> 2×2 [[dfx/dx, dfx/dy],[dfy/dx, dfy/dy]]
```

Jacobian 由核函数解析导数给出：`∂U/∂x = dx·(ln r² + 1)`，在控制点处（r=0）
方向导数取 0，结果有限。

## 错误语义（非法输入不静默纠正）

所有错误抛出 `TPSInputError`（`ValueError` 子类），信息携带可定位的下标/字段名；
退化构型抛出其子类 `DegeneratePointsError`。

- 坐标、`lam` 或 `confidence[i]` 为 `NaN` / `±Infinity` → 拒绝；
- `bool` 不是数字（`True/False` 即使可当 `int` 也显式拒绝，包括 `lam=True`、
  `confidence=[True, ...]`）；
- 非数值、点不是二元序列、空列表、源/目标长度不符、超过 40 点 → 拒绝；
- `lam < 0` → 拒绝；
- `confidence` 不是等长 list/tuple、含负数或长度不符 → 拒绝；
- **重复源点先判相容性：目标不同 → 拒绝**（即使其中一次置信度为 0；
  错误信息给出冲突的两个目标），目标相同 → 合并为一个控制点且置信度相加；
- 合并后少于 3 个不同点，或点共线（P 的数值秩 < 3）→ `DegeneratePointsError`；
- `lam = 0` 时任何 `confidence[i] = 0` → 拒绝（不受信的点无法被精确插值，
  错误信息提示改用 `lam > 0`）；
- `lam > 0` 时**正权重点少于 3 个，或正权重点共线** → `DegeneratePointsError`
  （仿射项与弯曲项必须由受信构型联合确定；零权重点再多也不提供仿射跨度）。

重复点判定采用转换后浮点数的**精确相等**，不做容差吸附（见已知限制）。
零置信锚点不进入求解系统，`weights` 中对应行为精确的 `0.0`，但仍出现在
`residuals` 中（用于观察它偏离曲面多远）。批次操作 `warp_points` 先整体校验
再计算，任何元素非法都不会产生部分结果；`fit` 为纯函数，失败不返回半更新
对象，已有的 `warp` 对象在任何失败调用后保持可用。求解为确定性直接消元，
数学上无解/不可解的情形统一由上述异常报告。

## 数值误差口径

IEEE-754 binary64（双精度），部分主元高斯消元。测试断言口径（不使用宽容差
掩盖边界错误，退化判定与容差相互独立）：

- `lam=0` 控制点恢复、纯仿射解析参考、本库 vs 独立参考实现（含**加权平滑**
  参考与 σ≡1 两条求解路径逐位一致）：**绝对误差 < 1e-9**
  （演示的 O(1) 坐标实测残差约 1e-15）；
- 零权重点 + 小 λ（1e-9/1e-7/1e-6）退化极限：与"剔除该点后的独立插值参考"
  逐点误差 < 5e-7（λ 有限引入的固有平滑偏差，随 λ 缩小趋于 0）；
- 坐标量级达 1e6（典型大像素坐标）：控制点残差与探测点输出的**相对误差 < 3e-9**；
- 约束 `Pᵀw = 0`：各分量绝对误差 < 1e-8（加权拟合驻点条件
  `w_i = σ_i r_i / λ` 同样以 1e-8 核对）；
- 解析 Jacobian vs 中心有限差分（h=1e-6，普通点，坐标 O(1)）：**< 5e-5**
  （控制点处用 h=1e-5，阈值 2e-4，因核函数在原点曲率奇异）；
- 共线判定阈值：离轴偏差小于构型直径 **1e-12** 倍即视为退化（约 4.5×10³ 倍
  机器精度，刻意收紧）；消元主元阈值为 `(m+6)·eps·max|A_ij|`。

阈值的含义明确：1e-12 直径以内的近共线构型会被当作退化拒绝，而不是带着
近奇异矩阵硬解。

## 设计取舍

- **自带稠密线性求解器**（`tps2d/_linalg.py`）：插值系统最大 43 阶、加权 KKT
  系统最大 46 阶，纯 Python O(n³) 消元为毫秒级，换取零依赖、可审计；
- 两输出坐标共用同一次消元（多右端项），不重复分解；
- **仿射与弯曲部分联合求解**：加权情形不做"先仿射去趋势再拟合弯曲"的分步
  近似，而是解一次 (w, a, μ) 的完整 KKT 系统；
- **内部归一化**：求解前把源点中心化并按点集直径 s 缩放到 [-1,1] 量级，
  目标点除以 s，正则量换算为 `lam/s²`。数据失配项随 s² 缩放、弯曲能
  `wᵀKw` 对均匀缩放无量纲，整体除以 s² 后**置信权重数值不变**。求解后把
  系数精确换回原单位（利用 `U(sr)=s²U(r)+s²ln(s)r²` 与 `Pᵀw=0`，二次附加项
  退化为并入 a0 的常数），公开系数、残差、Jacobian 全部保持调用方单位；
- **零置信点直接剔除**：残差形式 `I + KW/λ` 在 λ→0 时含 1/λ 项会破坏主元，
  而零权重点在增广系统中只被 `λK` 弱标识（实测 w 漂移 ~ε/λ）。因此 lam>0 时
  只对正权重点组 KKT 系统，零权点不进入任何核求和，w 行为精确 0，λ→0 的
  解连续收敛到"受信点插值 + 多余锚点无视"；
- 弯曲能直接由 K 与 `w` 组装（对角线 U(0)=0），报告的是**代数二次型
  `wᵀKw`（两坐标之和）**，不含经典物理泛函中的常数因子（如 8π 等），
  也不含 λ 罚项——`lam>0` 时它仍表示几何弯曲能，故应随正则增强而单调下降；
- 测试期望值来自闭式构造（已知仿射/平移）或 `tests/_reference.py` 中**从零另写**
  的独立参考（独立核函数、独立 Gauss-Jordan 消元、独立组装，含独立的加权
  KKT 组装 `reference_fit_weighted`），被测核心从不用于产生自己的期望值；
  权重单调性等往返一致性检查仅作补充；
- 不提供图像重采样 / 浏览器 / GUI，本模块只做点对曲面的 fit、warp 与导数。

## 已知限制

- 仅二维、控制点 ≤ 40；不实现 3-D TPS、多级配准、鲁棒迭代（异常点需调用方
  通过 `confidence` 显式降权）或 Jacobian 无翻折认证；
- 重复点按精确浮点相等判定，不做近邻吸附/容差合并（需要时由调用方预先归并）；
- 置信权重为固定的各点独立二次失配权重，不支持协方差矩阵 / 各向异性噪声；
- 弯曲能为代数口径 `wᵀKw`，未乘经典文献的归一化常数；
- 近退化构型（受信点离轴 < 1e-12 直径）一律报退化，不尝试奇异值截断求解；
- 不声明与任何行业配准标准的完整兼容性，只实现本契约的数学子集。
